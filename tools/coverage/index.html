Покрытие картинок: какие ключи обязаны быть в паке

кадров на ключ: частые обычные хвост частые = ключи до % показов сцены

Как читать. Ключ = сцена / кто / фон / теги. У каждой сцены свои оси (наряд, лицо, растяжение...). Режим оси: все сочетания - каждое значение с каждым значением других таких осей; каждое хоть раз - каждое значение встречается хотя бы в одном ключе; подбор - не рисуем отдельно, игра подставит ближайший кадр.

Гарантия - сколько ключей сцена обязана иметь. pack26 - сколько из них уже нарисовано в паке 26.11, старые - есть только в старых кругах (pilot55/p2/r*), нет - не нарисовано нигде. Кадров - сколько кадров нужно на сцену по правилу "частые / обычные / хвост".

Клик по сцене - настройки справа: режим и значения каждой оси, свои кадры на ключ, выключить сцену. Всё пересчитывается сразу; "Сохранить" пишет docs/pics/coverage.json.
