# Как добавить новый акт (для Алексея / Grok)

Код и цифры делает Claude. От автора текстов нужна только **одна анкета на акт** - её можно отдать Grok и прислать ответ как есть.

## Анкета (скопируй и заполни на каждый акт)

```
id: ignore_handjob            # латиницей, без пробелов
кто кому: она ему / он ей / оба
ступень 0-9: 6                # как далеко это: 1 флирт, 4 руки, 6 рот, 7 секс, 9 самое дальнее
нужна ли его эрекция: да / нет
нужна ли игрушка: нет / страпон / дилдо
это про власть над ним: да / нет     # фемдом-акты: да
где возможно: только спальня / любая закрытая комната / хоть в зале

тексты (по-русски, прямые кавычки, дефис вместо тире):
1. название в меню: "..."                       # 2-4 слова
2. как он просит: "..."                         # кнопка, от первого лица мужа
3. название сцены под картинкой: "..."
4. она соглашается и начинает: "..."            # 1-2 предложения
5. идёт, обычный ход (3 варианта): "..." / "..." / "..."
6. она ведёт и сама это выбирает: "..."
7. он кончает: "..."
8. название сцены "после": "..."
9. она отказывает и предлагает это вместо секса: "..."   # только если это фемдом-акт

поза для картинки (словами, по-английски можно): кто где, кто как стоит/лежит, куда руки
```

## Что из этого получится в игре
- п.1 -> `act.<id>`, п.2 -> `action.night.<id>`, п.3 -> `scene.<id>`, п.7 -> `log.bed.his.<id>`, п.8 -> `scene.came_<id>`, п.9 -> `log.night.counter.<id>`.
- "ступень" -> `tier` и стартовая сложность согласия; "про власть" -> акт попадает в список "его" актов (она может выбрать его, когда ведёт, и он растит её власть); "без эрекции" -> акт доступен, когда он уже кончил или упал.
- Поза -> фигурки в `scenes.yaml` и строка в `prompt.yaml` для картиночного чата.
